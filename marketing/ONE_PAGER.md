# manyhouses — One-Pager

**Find property across Egypt in one place.**

## The problem

Looking for a home in Egypt means checking Facebook groups, OLX and agents one by one. It is hard to compare places in different cities, and there is no simple way to keep a shortlist.

## What manyhouses does

- **Browse** properties in 10 cities, with photo, price and details
- **Search** by name, city or type
- **Map** each property's location on its details page
- **Save favorites** with one click, for the length of your visit
- **Draft a contract** in the app and download it as a text file
- **Ask questions** through the FAQ and the contact page

## Where it is now

- A working demo built with Streamlit, a Python web framework
- 12 sample properties in 10 cities, across 4 property types
- One library (Streamlit), so it runs on any Python host
- Not yet built: real listings, real accounts, and delivery of contact messages
